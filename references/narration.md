# 旁白稿怎么写

## 第一原则：旁白稿 ＝ 画面字幕的口语化版本

好的片子画面里本来就有**自包含解说**（静音也看得懂的那条）。写旁白时**照它改口语**，
不要另起炉灶——否则观众听到的和看到的是两套措辞，读起来别扭，字幕也没法复用。

实操：把每一镜的 caption（+ sub 细节）念一遍，删掉书面语的连接词，补上"你/它"的主语。

| 画面注解（书面） | 旁白（口语） |
|---|---|
| 有订阅、也有代理，卡在第一步：claude 登录不上 | 有订阅，也有代理，第一步就卡住：claude 登录不上。 |
| 当场体检：出口 IP、地区、运营商、这一跳有没有加密 | 当场体检：出口地址、地区、运营商，还有这一跳有没有加密。 |

## 长度：按镜头时长倒推字数

清爽男声约 **3.3–3.8 字/秒**（含停顿）。一条镜头能装的字数 ≈ `时长(s) × 3.5 - 2`。

| 镜头时长 | 安全字数 |
|---|---|
| 2.4s（字卡） | ≤ 8 字 |
| 3.9s | ≤ 12 字 |
| 5.4s | ≤ 17 字 |
| 5.9s | ≤ 19 字 |

超了不是不行——钉帧器会顺延，但**顺延不能跨出这句话所描述的画面**。
实测两支片里各有 2 句必须缩写重合成。

## 密度：留白优先

152 卡演示片 4:25 全片只有 16 句、73s，占 28%。**画面自己会说话的地方不配音**——
镜头墙、纯动效段、品牌落定的 hold，都让它安静。判据：这一句是否给了画面没给的信息？
没有就删。

## TTS 文案禁忌（合成前扫一遍）

- **多音字**：走 hfvoice（SAMI/edge）时避开「一行」（会念 xíng，改成「一句/一条/一段」，或后面紧跟汉字）、
  「长出」（cháng/zhǎng 歧义，改「有」）、「都得」（děi/dé 歧义，改「都要」）。
  🔴 走 `voxvoice`（VoxCPM2 克隆音）时**不必套这套规避**，实测「行/塞/重新」都念对。
- **中英混排**：清爽男声在英文白名单里（Claude / Agent / prompt / MCP / token / API / code 实测全准），
  可以放心写产品名；换其它音色前先查白名单，163 个音色里约一半会把 Claude 念崩。
- **引号**：TTS 会把成对引号读成停顿，句子里尽量不用；字幕层会去标点，引号留着只会变成空格。

## 一句一行，一行一句

稿子存成 `vo/narration.txt`，**一行一句**，行号即钉帧顺序（第 N 行钉到第 N 个镜头/锚点）。
中途改某一句：只重合成那一行，其余不动。
