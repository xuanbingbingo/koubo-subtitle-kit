# 音频资产（不随仓库分发）

BGM 与音效**不放进本仓库**：这类素材的免费授权通常允许"用于你的作品"，但不允许"再分发素材文件本身"。
自己下一份放进你工程的 `public/audio/` 即可。

## 推荐来源

| 来源 | 授权 | 适合 |
|---|---|---|
| [Mixkit](https://mixkit.co/free-stock-music/) | Mixkit License，免费商用免署名 | 产品宣传片鼓底 BGM、电影系音效（whoosh / impact / riser / sparkle） |
| [Pixabay Music](https://pixabay.com/music/) | Pixabay License，免费商用 | 通用 BGM |
| [incompetech](https://incompetech.com/) | CC-BY 4.0（**需署名**） | 曲库大、按情绪筛选 |
| [freesound](https://freesound.org/) | 逐条不同，注意看 CC0 / CC-BY | 拟音 |

🔴 下载时就把曲名与 URL 记进 `ATTRIBUTION.md`——批量下载后 metadata 常被抹掉，事后无法反查授权。

## 选曲判据（产品片）

鼓点强、节奏稳的电子底（tech-house 类）；"好听 / 欢快"不是判据。
闭眼只听音轨，应该像产品发布会预告，而不像手机游戏。
**候选曲必须垫进成片试听**——单听曲子选型不可靠。

## 音量

有旁白时 BGM 基线 0.18–0.20，纯音乐版 0.20–0.26，细则见 `references/mixing.md`。
